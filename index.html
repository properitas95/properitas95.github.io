One result

Same stock, same dividend: exchanges settle it about one full dividend apart

Equity perpetual futures on Binance, OKX and Bybit, matched dividend events, 2026. Difference in what each venue’s settlement path credits, in units of the dividend D.

Is the gap worth trading?

In 20 of 27 events the dividend yield exceeds a 10 bp four-trade cost; in 14 it exceeds 20 bp.

A screen, not an execution study: contemporaneous bid–ask quotes and fees were not observed. Source: D. Seo et al., Basis-only funding is not dividend fair, MARBLE 2026.

Software

ResearchLab

Code and README in Korean.

A research harness that takes one question from the literature to a reviewed result. Language models read, design experiments, write code and critique, but a frozen evaluator and fixed rules decide whether a result holds. Each trial changes one file and is kept only if it beats the best so far by a preset margin; the holdout sample opens once per question; every run ends in one of four verdicts. Python standard library only.
